# Live Change Plans

Create one live tracker per planned change in this folder.

Quick start:

```bash
cp docs/CHANGE_PLAN_TEMPLATE.md docs/plans/YYYY-MM-DD-short-change-title.md
```

Required usage:
- update the tracker after every code change
- include one Change Log entry per implementation step
- record verification commands and outcomes continuously
- complete final self-audit before handoff or PR
